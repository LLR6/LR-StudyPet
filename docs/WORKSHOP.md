# 星梨桌宠创意工坊：做自己的桌宠

这是软件内的本地工坊，可以制作、预览、安装、切换和导出角色包。无需账号。当前没有在线商店、审核服务或云端生成器。

## 最简单：一张图就能开始

1. 打开「创意工坊」，填写角色名称、作者和素材许可。
2. 在「待机」一行选择透明 PNG（建议 512×512）。GIF 和 WebP 也可。
3. 保持「打字时叠加双手与键盘」勾选，点击「制作并安装角色」。
4. 选中左侧新角色，点「应用选中角色」。
5. 在「桌面助手」打开键盘联动，在记事本里敲键体验。

单张图可以跟随呼吸浮动和键盘动作，不会自动变成完整多姿态动画。普通照片的背景也不会自动移除，建议先用自己的绘图工具做成透明素材。

## 进阶：给每种动作单独做素材

| 状态 | 触发条件 | 推荐素材 |
|---|---|---|
| 待机 idle | 无近期敲键、未专注 | 轻微呼吸或眨眼 GIF |
| 打字 typing | 敲键或按住按键 | 双手打字 GIF，或透明 PNG + 程序键盘动作 |
| 睡觉 sleep | 停止敲键达到设置时长，且未专注 | 睡觉 / Zzz GIF |
| 读书 focus | 处于专注计时，当前没有敲键 | 读书 PNG/GIF |
| 庆祝 celebrate | 完成专注或完成任务 | 欢呼 PNG/GIF |
| 休息 rest | 处于休息计时 | 伸懒腰 PNG/GIF |
| 摸头 pat | 点击摸头互动 | 开心 / 摸头 PNG/GIF |

缺失动作回退到待机。自己的打字 GIF 已经包含手和键盘时，取消键盘叠加，避免画两套手。
同一动作里的 GIF 持续播放，不会每次按键都从头重播。
Windows 的全局键盘联动只在手动开启后工作；其他平台目前只响应软件内部按键。

## 一键导出模板与分享

点击「导出星梨制作模板」获得 `.lrpet` 文件。它实际是 ZIP，含 `pet.json` 和 PNG 素材。
可以直接导入体验，也可解压后替换图片，保持文件名，再压缩根目录里的配置和图片。
不需要手写配置：在工坊表单选择各动作的 PNG/GIF，然后制作、导出，也能得到完整角色包。

示例配置：

```json
{
  "schema": 1,
  "name": "我的小蓝猫",
  "author": "你的昵称",
  "license": "原创，仅个人使用",
  "keyboard_overlay": true,
  "states": {
    "idle": "idle.png",
    "typing": "typing.gif",
    "sleep": "sleep.gif"
  }
}
```

文件名只用英文、数字、`-`、`_`，扩展名为小写 png/gif/webp。名称和作者可以用中文。
图片最长边不超过 2048 像素，单素材不超过 8 MB，单段动图最多 240 帧。建议每动作 8～24 帧、8～15 FPS、统一画布与人物位置。
角色包根目录必须直接包含配置和引用的图片，不要额外套文件夹。

导出后可把包发给朋友，由对方在工坊导入。分享前确认你有权分发素材，并保留作者与许可。
工坊只导入图片与配置，不加载脚本、插件或远程代码。导入会检查大小、路径和素材有效性。

## 用绘图工具或 AI 准备素材

「复制画图提示词」会把制作要求复制到剪贴板，可以粘贴到自己的绘图工具。它不会在后台联网、调用模型或扣费。
先确定角色的造型、配色与衣服，再制作各动作；不要一次生成一个没有明确网格的大拼图。
如果想借助 AI，先做透明待机图并确认一致性，再逐一做读书、睡觉、庆祝等姿态。连续动画需要逐帧制作或动画工具。

## 数据位置

已安装角色在 `%LOCALAPPDATA%\LR-StudyPet\pets`。学习 JSON 备份不包含角色图片；需要长期保留的角色请单独导出 `.lrpet`。
默认星梨始终可从工坊恢复，原有学习数据不会因换角色而改变。

## 参考与区别

体验参考 [DesktopCat](https://desktopcat.com/zh) 的输入反馈、待机/休息和角色包思路，以及 [RemiPet](https://github.com/mmisitan0925-afk/-RemiPet) 的按键/松开切换与连续 GIF。
RemiPet 当前代码是 Electron/JavaScript，README 的 Python 说明与代码不一致。本项目只参考交互思路，没有复制其代码或角色素材。
本项目使用自写 Windows 事件监听、Qt 动画和数据型角色包，工坊不是其他项目包格式的兼容导入器。
