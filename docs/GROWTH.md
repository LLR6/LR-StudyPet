# StudyPet：从第一批 Star 到真实留存

2026-10-09 查询 GitHub 时：2 Star、0 Fork、0 Issue，v0.2.0 Windows 包累计 2 次下载。下载计数不代表独立用户，更不能等同活跃使用人数。未获得访问来源、安装反馈和留存数据；不能断言某个功能导致了 Star。

## 可检验的吸引力假设

| 假设 | 仓库中的依据 | 怎么验证 |
|---|---|---|
| 角色和互动让人一眼看懂 | 原创蓝色女孩、键盘联动、摸头、预览图 | 反馈表询问最先吸引你的是什么 |
| 情绪陪伴有现实入口 | 专注、小任务、精力推荐、中断书签 | 询问实际使用最多的功能和放弃原因 |
| 下载门槛低 | Windows 便携包含运行环境 | 记录启动成功/失败的自愿反馈 |
| 实用性让人留下 | 本地复习卡、任务、手记、备份 | 收集一周后仍会打开的原因 |
| 本地优先使功能更容易接受 | 不依赖 AI 也能使用，剪贴板默认关闭 | 询问是否因为离线能力而尝试 |

这是初步兴趣信号。暂不宣称产品成功，不承诺 Star 增长。

## 本轮扩展的选择

- StudyPet：保留视觉和学习陪伴，增加复习卡迁移、周报、多屏修复。
- LR-ResumeDock：把中断书签变成学习、写作、编码都能用的独立浮窗。
- LR-DeskTidy：把只读桌面建议延伸为计划预览、选择性移动和可撤销操作。

每个项目要有清楚的问题、运行入口、真实截图、测试和边界；避免只是换名字复制功能。
新工具当前作为 companions 提供，独立仓库尚需创建；它们不依赖 StudyPet 的代码或数据。

## 接下来衡量什么

先看外部反馈中有多少人启动成功、实际用到哪个功能、为何放弃，再看 Star。可以用 GitHub Issues 的使用反馈表收集；不增加埋点或自动上传。

每次新增功能提供一个 30 秒可复现案例；发布说明写实际完成的变化。后续优先考虑自定义皮肤和系统主题适配，依据反馈安排。
